Vision-Language-Action 모델 위에
AI Agent를 얹는 기록

TIC-VLA 논문 모델을 SerBot II 3륜 옴니 로봇에 온보드로 얹고, 그 위에 AI Agent를 올려 심부름을 자율 수행시키기까지의 개발 일지입니다.

추론 지연, 좌표계 검증, 안전 계층 설계, 실차 주행까지 — 잘 된 것과 틀렸던 가설을 함께 남깁니다. rule-based로도 되는 것과 AI Agent여야만 하는 것을 가르는 과정도 남깁니다.

  • 1.8 GBInternVL3-1B 온보드
  • 11.9 msAction Expert 추론
  • 72학습 데이터 에피소드
  • 0.03641차 학습 ADE (학습 전 0.1623)
  • 23.4 sVLM 재해석 주기
  • 2층Agent 판단 + VLA 실행
현재 상태 — 시스템 구조(L0~L4) 확정, 관측 품질이 블로커
  • ReAct live 연동 경로 동작 — 그러나 실제 <think>가 장면을 서술하지 못해 goto 0회
  • 구조 결정: ReAct(L3)는 멈춰서 판단, TIC-VLA(L1)는 움직이며 실행 · 도착 정지는 LiDAR + 카메라 확인
  • 미구현: L2 goto 주행 연결, L4 심부름 관리자, 터치 UI, LiDAR 연동, VLM LoRA
  • 다음: 관측 방식 비교로 기준선 확보 → 신규 4종 에피소드 수집 → VLM LoRA
